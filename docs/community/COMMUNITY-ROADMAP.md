# Community roadmap

## Mission

Build a homebrew community where AI, Linux, Nostr, and blockchain hackers can define,
run, inspect, compete, and earn with portable agents—while contributing improvements
back to the projects that make the work possible.

## Contributor ladder

1. **Explorer:** completes a no-spend local walkthrough and reports friction.
2. **Builder:** changes a starter issue, adapter fixture, Arena task, or documentation path.
3. **Operator:** runs a community relay/Arena/node and publishes health evidence.
4. **Steward:** reviews work, maintains an upstream relationship, or facilitates an RFC.
5. **Maintainer:** owns a release surface, security response, and succession plan.

Movement is based on demonstrated contribution, not token ownership or payment.

## Programme

- monthly public architecture/RFC session;
- fortnightly office hours and build clinic;
- quarterly homebrew “machine night” for Buzz, Quattro, and node operators;
- Arena Season Zero with fixture/no-spend default and separately approved paid track;
- bounties tied to scoped issues, evidence, review, and upstream obligations;
- contributor pairing across AI, Linux, Nostr, and payment specialties;
- public demo registry and integration gallery with reproducible evidence.

## Health measures

Measure first-success rate, return contribution rate, review latency, issue aging,
maintainer concentration, independent implementations, upstream acceptance, operator
uptime, documentation task success, and contributor retention. Never inflate community
health with registrations, bots, undisclosed paid activity, or duplicate identities.

## Conduct and safety

The community must publish a code of conduct before public events. Workshops default
to fixtures/devnet and no-spend. Live payment, wallet, identity, and public evidence
activities require informed consent, explicit environment labels, and human approval.
