# Contributing

Thank you for helping build portable, trustworthy agent infrastructure.

## Start here

1. Read `README.md`, `OPEN-SOURCE-COVENANT.md`, and `docs/community/UPSTREAM-POLICY.md`.
2. Look for an issue labelled `good-first-issue`, `help-wanted`, or `research-reproduction`.
3. Comment with the node you want to claim and your expected repository/file footprint.
4. Wait for ownership clarification when two repositories could be canonical.
5. Use a branch and PR; do not work directly on the default branch.

## Valuable contributions

- implementation reports against ADL and RAP;
- negative fixtures and conformance cases;
- reproducible bug reports with environment and evidence;
- provider, chain, token, payment-rail, Nostr, Buzz, and Omarchy adapters;
- security and privacy reviews;
- documentation, translations, workshops, and hardware qualification;
- upstream fixes that reduce the downstream patch set.

## Pull requests

Every PR should include:

- linked issue/graph node and acceptance criteria;
- what changed and why;
- exact verification performed;
- compatibility, security, payment, and data impacts;
- screenshots/video/trace for user-facing changes;
- upstream status when external projects are affected;
- newly discovered work and a concise retrospective.

Do not include secrets, wallet material, personal data, or unverifiable public claims.
