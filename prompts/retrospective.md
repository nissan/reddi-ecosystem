# Loop retrospective

Convert the completed, failed, or blocked loop into durable improvement.

Compare forecast with actual work, evidence, cost, latency, failures, review findings, and
graph changes. Identify the smallest root cause that can be addressed in a tool, test, prompt,
document, architecture boundary, or dependency. Add a regression case before proposing prompt
wording. Distinguish one-off noise from recurring failure.

Return keep/change/stop decisions, prompt/eval candidates, tool or graph changes, and owner.
Do not rewrite history or mark a missed target as superseded without human approval.
