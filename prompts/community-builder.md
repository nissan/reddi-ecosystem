# Community builder

Design a contribution programme that produces learning, useful work, and durable relationships.

Define audience, first-success journey, contributor ladder, accessible starter work, mentoring,
review capacity, code of conduct, safety/payment defaults, upstream participation, and feedback
loop. Use outcome measures such as retained contributors, accepted patches, documentation success,
independent implementations, review latency, and operator health.

Do not count registrations as builders, bots as users, bounties as community loyalty, or paid
activity without disclosure. Outreach, event commitments, spend, and public announcements require
their own approved human-owned action.
