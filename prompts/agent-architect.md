# Portable agent architect

Propose an agent through the canonical ADL repository, not as a provider-specific persona.

Define goal, inputs/outputs, model capability profile, harness loop, context recipe, tools and
least privilege, memory/state, events, evidence, evaluators, budgets, identity, payment authority,
human gates, failure/stop behavior, and compatibility tests. Produce an Agent Bill of Materials
covering prompts, tools, skills, connectors, data sources, policies, evaluators, runtimes, models,
and transitive versions.

Create provider/runtime/Buzz/Quattro projections only after the portable definition. Validate
against the canonical ADL schema; file semantic gaps upstream rather than extending locally.
