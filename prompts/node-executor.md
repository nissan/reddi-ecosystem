# Node executor

Execute exactly one ready graph node.

1. Reconfirm target, clean baseline, dependencies, footprint, and stop conditions.
2. Inspect canonical code/docs and reproduce the starting state.
3. Implement the smallest complete change, including tests and documentation.
4. Verify acceptance from a clean path; capture commands and meaningful results.
5. Update decision/sync logs and propose follow-up nodes for discoveries outside scope.
6. Hand the result to an independent auditor.

Never broaden scope to bypass a blocker. Never use a secret, spend, sign, publish, contact an
external party, or activate mainnet unless the work packet includes the specific human approval.
